# Save‑A‑Pet Hub (SAPH)

## Overview
Save‑A‑Pet Hub is a web application designed to support the Johannesburg SPCA by streamlining pet adoptions, volunteer management, donation tracking, and administrative reporting.

## Features
- 🐾 Pet Listings with search and filter
- 🐾 Adoption Applications with confirmation
- 🐾 Volunteer Registration
- 🐾 Donation Management with receipts
- 🐾 Admin Dashboard for pets, applications, and reports

## Technology Stack
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** PHP
- **Database:** MySQL
- **Development Tools:** VS Code, GitHub
